02 / OPTIONAL✳

Connect an AI assistant

Connect Codex or Claude Code while your Anki profile is open.

  1. In Anki, select Tools → Better Anki Markdown: Connect Codex.
  2. Restart Codex and open a new chat.

The local server starts with your Anki profile. This action saves the connection in your Codex config. Your collection is not synced automatically.

For Claude Code, choose Tools → Better Anki Markdown: Connect Claude in Anki, or run:

CLAUDE CODE
claude mcp add --transport http --scope user better-markdown-anki http://127.0.0.1:19176/mcp

Start a new Claude Code session after setup. This configures Claude Code; the Claude Desktop chat app uses separate settings.

Connect another MCP client

Open an Anki profile, then add a Streamable HTTP server at http://127.0.0.1:19176/mcp.

For Copilot CLI, run:

COPILOT CLI
copilot mcp add --transport http better-markdown-anki http://127.0.0.1:19176/mcp

In Antigravity, open the agent panel menu → MCP Servers → Manage MCP Servers → View raw config, and add the URL as a serverUrl entry.

Local by default. The server listens only on 127.0.0.1. While enabled, local programs can read and change the open collection. Don’t expose the port publicly.
